## What's new in 2.3.0

### AI Assistant
- `--agentic-provider bedrock` runs the AI Assistant on Amazon Bedrock with an API key: `EDAMAME_LLM_API_KEY` (or `AWS_BEARER_TOKEN_BEDROCK`), `EDAMAME_LLM_REGION` (or `AWS_REGION`) and `EDAMAME_LLM_MODEL`; `EDAMAME_LLM_REASONING_EFFORT` is optional. A missing model id logs the models the key can call, and the daemon tests the model once it is configured.

### Detection
- Improved attack detection and fewer false alarms.

### Other
- Security and stability improvements. Updating is recommended.
