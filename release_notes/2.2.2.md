## What's new in 2.2.2

### Detection
- Improved attack detection and fewer false alarms.
- Fewer duplicate records for a finding that stays active.

### Notifications
- A security alert leads with the findings that are new and counts the ones already reported.
- Frequent notifications no longer push rarer security alerts out of the notification history.

### Network
- The ICMP sweep of a network scan reaches every address of the range.

### Other
- Security and stability improvements. Updating is recommended.
