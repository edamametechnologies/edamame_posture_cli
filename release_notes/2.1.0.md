## What's new in 2.1.0

### Detection
- Improved attack detection.
- Fewer false alarms when monitoring AI agents.

### Monitoring
- Standing permissions: allow an AI agent a destination, port or scope for good (`agentic_add_standing_grant`, `agentic_list_standing_grants`, `agentic_remove_standing_grant`).
- Sensor coverage: `get_coverage_status` reports which monitoring sensors are running, and a notification is raised when one that protection relies on stops.

### Other
- Security and stability improvements. Updating is recommended.
