## What's new in 2.0.4

### Installation
- **Intel Macs.** The macOS binaries start on Intel Macs.
- **The installed binary is the one that runs.** `install.sh` verifies and starts the `edamame_posture` it just installed (or chose to keep). When another copy comes first on `PATH`, it is reported with its version, so a plain `edamame_posture` command does not silently reach an old installation.

### Other
- Improved detection.
- Fewer false alarms.
- Security and stability improvements. Updating is recommended.
