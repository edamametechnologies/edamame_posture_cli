## What's new in 2.0.5

### Domain-managed settings (preparation)
- **`--accept-managed-config`** (or `EDAMAME_ACCEPT_MANAGED_CONFIG`) on `background-start` and `foreground-start`: whether this daemon applies the settings its EDAMAME Hub domain manages for CI/CD or posture devices. `always` accepts them, changes included; `sha256:<fingerprint>` accepts that configuration only. Without it, a managed configuration is reported declined and the daemon keeps its own settings and its Hub connection. Domains can publish managed settings in a later EDAMAME Hub update.

### Other
- Network connections are attributed to the right process more accurately.
- Fewer false alarms.
- Security and stability improvements. Updating is recommended.
