## What's new in 2.0.3

### Installation
- **macOS installs the PKG only.** The raw macOS binary is no longer published; `install.sh --force-binary` installs the PKG and `--debug-build` the debug PKG. An installed PKG is upgraded when a newer release is published and never downgraded.
- **Downloads are verified.** `install.sh` checks every binary and PKG against the checksums its release publishes, and stops when a download does not match.
- **No silent fallback to old releases.** When the latest release cannot be looked up or downloaded, `install.sh` stops with the reason instead of installing an older version.
- **Debian / Ubuntu upgrades keep your configuration without asking.** `/etc/edamame_posture.conf` is no longer a packaged configuration file: upgrades never stop at a configuration question and never touch an existing file.

### CI and daemons
- **Gates on persistent runners count only findings first seen during the job.** `attack-pattern-status --fail-on-findings --since <time>` fails only on findings first seen at or after that time; older active findings are printed as warnings with their first-seen time. The daemon's live gate applies the same rule from the job's setup time.
- **A managed policy that refuses `--agentic-mode` stops the start.** When the organization's policy locks agentic protection, a daemon started with a mode it refuses exits with code 3 and the organization's reason, instead of running without the requested protection.
- **Whitelist commands.** `set-whitelist <name>` enforces a named whitelist (an unknown name exits 3). `evaluate-custom-whitelists-from-file` and `augment-custom-whitelists-from-file` check or extend a whitelist file against the egress traffic seen since a given time (`--since`), as the posture action's auto-whitelist does. `set-custom-whitelists` exits non-zero when the daemon refuses the whitelist, and the commands that change the enforced whitelist require administrator rights.
- **Windows:** a Windows path in a double-quoted service configuration value keeps its backslashes.

### Other
- Threat models are checked against their signatures before use.
- Fewer false alarms.
- Security and stability improvements. Updating is recommended.
